# Firmware packages to register into the Debian/Ubuntu dpkg database.
#
# Scope: the firmware files that are actually present on this board's rootfs
# but unowned by dpkg.  Measured on QCS6490 / Debian 13 (2026-11):
#   587 unowned files under /usr/lib/firmware
#   578 of them are shipped by the packages listed below
#   the remaining 9 have no deb at all (see the end of this file)
#
# Packages for other SoCs (qcs8300 / qcs9100 / qcs615) are deliberately NOT
# listed even though they define file paths that happen to exist here: they are
# a different platform's firmware and would only add dead weight and
# cross-platform dependency noise.
#
# Add lines here to track more; see ../README.md for the mechanics.

# /usr/lib/firmware/qcom/venus-5.4/venus.mbn.  dpkg refuses to unpack two
# packages owning the same path (the later one rolls back to not-installed), so

# the vpu-2.0 / vpu-3.0 blobs that the generic package does not.
